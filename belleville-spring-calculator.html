Almen-Laszlo 核心公式
P = [4E·t⁴ / ((1−ν²)·De²)] × [K₁(h₀ₑff−s/2)(s/t) + K₂(s/t)²]
h₀ₑff = h₀ − 2d　　（有效錐高，磨平修正後） K₁ = (1/π)·[(δ−1)/δ]²/ln(δ)　　δ = De/Di K₂ = (6/π)·[(δ−1)/ln(δ) − 1]

d = 磨平高度，發生於外緣底角與內緣頂角各一處，每處磨去垂直高度 d
外緣底角磨平 → 支撐點上移 d；內緣頂角磨平 → 加壓點下移 d
有效總高度 h₀+t−2d　　其中 h₀ = 名義錐高，t = 材料厚度，h₀ₑff = h₀−2d（計算用）
De = 外徑　　Di = 內徑　　E = 楊氏模量　　ν = 泊松比　　s = 工作撓度
